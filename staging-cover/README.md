# バーチャルステージング 出品の1枚目（ビフォー→アフター比較画像）

| ファイル | 使う場所 |
|---|---|
| `staging-cover-ja.png` | ランサーズのメニュー（日本語） |
| `staging-cover-en.png` | Fiverr のギグ（英語） |

- サイズは 1280×769（Fiverr のギグ画像の比率）。ランサーズでもそのまま使えます。
- 部屋写真は自作のサンプルです（OpenAI の画像生成で作った架空の空室と、同じ写真に家具を置いた版。実在の物件・人物は写っていません）。画像の右下にもその旨を入れています。
- 元の写真：`src/before.png`・`src/after.png`（1536×1024）。文字を変えるときは `cover-ja.html`／`cover-en.html` を直して、Chrome のヘッドレスで撮り直します。
