# 滑らか動画の標準（アフィリエイトリール／短尺動画 共通）

2026-11-20、社長（修平さん）の指摘で定めた標準。最初の制作（静止画＋クロスフェード）は「動きがコマ撮りすぎる」と却下された。

## 絶対ルール
- シーン部分は「本物の動きのある動画クリップ」を使う。静止画のポーズ違い＋クロスフェードで代用しない。
- 動きのクリップが渡されていない、かつ自分の環境で生成できない場合は、組み立てに入る前に必ず報告する（コマ撮りのまま納品しない）。
- 音楽は動画ごとに別の曲にする（同じ曲の使い回しをしない）。Kevin MacLeod（CC BY 4.0）を使い、キャプションに必ずクレジットを入れる。

## 見本
- `affiliate-reels/smooth-standard/affiliate-warm-smooth.mp4`（この標準で作った完成品。ffmpegでフレームを抜いて構成・テロップ・PR表示を確認すること）

## 組み立てテンプレート
- `build_warm.py` / `build_two.py`（このフォルダ内）
- 構成：カバー0.5秒（写真＋大きな見出し＋PRバッジ）→ ビフォー5.5秒（動画クリップ＋下部テロップ）→ アフター6.5秒（動画クリップ＋テロップ2枚）→ 商品カード4秒 → エンドカード3秒 ＝ 計19.5秒
- 形式：1080x1920、H.264 High、yuv420p、30fps、音楽はAACでフェードイン／アウト
- テロップは白い丸 pill＋黒太字（PILで画像化して重ねる）。PRバッジは全編右上。

## 素材の分担
- ハトル（Muse側）が「写真・動画クリップ・音楽ファイル」を用意して渡す。
- Claude Code は組み立て（テロップ合成・カード・エンド・音楽付け）を担当する。
- クリップが不足していたら、静止画で埋めずに「クリップが足りない」と報告する。
